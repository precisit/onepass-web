Connect Four: one model, two runtimes (Speed)

Can the same 7.4 M parameter model as in the main demo run faster? Yes: with custom kernels in onepass-webgpu, a small WebGPU runtime, from the fp32 file or the main demo's int8 file, compared with onnxruntime-web on WebAssembly. A perfect Connect Four solver is timed alongside: faster on most moves, but far less consistent. The story behind it: One millisecond to make a move.
